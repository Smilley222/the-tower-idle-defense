# Changelog

## V1.1 — playable browser demo
- Corrected simulation time scaling for 1×, 2× and 4×.
- Added pause / resume and manual **Next Wave** control.
- Added keyboard shortcuts alongside touch controls.
- Improved responsive UI and combat feedback.
- Preserved and validated Workshop save data via `THE_TOWER_IDLE_SAVE_V1`.
- Added Workshop save export/import.
- Allowed spending earned Coins after game over before starting the next run.
- Applied Workshop upgrades to subsequent runs rather than mid-run.
- Added personal best wave tracking.

## V1.0 — initial prototype
- Single central auto-firing tower.
- Normal, Fast and Tank enemy waves.
- Cash-based in-run Attack, Defense and Utility upgrades.
- Permanent Coin-based Workshop progression.
- Canvas combat visuals and neon UI.
