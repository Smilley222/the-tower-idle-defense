# Development Roadmap

Current milestone: **V1.1 playable browser foundation**.

| Version | Focus | Status |
| --- | --- | --- |
| V1.1 | Correct speed, manual waves, pause, save portability, UX | Shipped |
| V1.2 | Boss fights, additional enemy mechanics and graphics | Planned |
| V1.3 | Expanded Workshop and achievements | Planned |
| V1.4 | Offline rewards and idle automation with balance safeguards | Planned |
| V1.5 | Controller/gamepad support and accessibility polish | Planned |
| V2.0 | Prestige and advanced tower modules | Concept |

## Release checklist for each version
1. Verify early game waves and upgrade affordability.
2. Verify 1×/2×/4× gameplay consistency.
3. Test pause, manual waves, auto waves, death and restart.
4. Test Workshop Coins and legacy save compatibility.
5. Test on desktop Firefox and a mobile viewport.
6. Update README and CHANGELOG before publishing.

## Future publishing
The Tower can appear as a standalone GitHub Pages game and later link into the GEO Arcade collection.
